Java implementation of Huffman coding that builds an optimal prefix-code tree with a priority queue, encodes and decodes text, and verifies round-trip correctness. Reduced a 2.35M-bit Project Gutenberg book to 1.44M bits, a 38.75% saving over fixed 7-bit encoding.
